📖 Como obter as credenciais
API Key:
1. Acesse console.cloud.google.com
2. Crie um projeto → APIs e Serviços → Biblioteca
3. Pesquise e habilite YouTube Data API v3
4. Vá em Credenciais → Criar credencial → Chave de API

Live Chat ID:
1. No YouTube Studio, inicie uma transmissão ao vivo
2. O Live Chat ID aparece na URL do chat:
youtube.com/live_chat?v=LIVE_CHAT_ID
3. Ou pela API: youtube.com/live/VIDEO_ID
